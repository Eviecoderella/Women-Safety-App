# Women's Safety App

The solution combines real-time threat detection, analytics, and support resources. Using surveillance camera data, it detects potential dangers and sends immediate alerts to the user’s mobile app, ensuring timely assistance. The app also includes features like evidence-saving, mental health support through NGO connections, and access to safety tips and self-defense resources, creating a comprehensive safety companion for women.
